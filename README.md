# Shanzay Hussain — Portfolio

React + TypeScript + Tailwind + Framer Motion.

## Run it
```
npm install
npm run dev
```

## Build for production
```
npm run build
```
Output goes to `dist/` — deploy that folder to Vercel/Netlify.

## Where things live
- `src/components/Hero.tsx` — the cursor-tracked skeleton-reveal effect
- `src/assets/` — your avatar + project cover images (swap these anytime)
- `src/components/*.tsx` — one file per section
- `tailwind.config.js` — the color/font theme tokens
